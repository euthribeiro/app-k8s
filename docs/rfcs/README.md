# RFCs — Request for Comments

Decisões técnicas relevantes discutidas antes de virarem implementação. Diferente dos
[ADRs](../adrs), que registram decisões arquiteturais permanentes e já tomadas, um RFC expõe o
raciocínio, as alternativas e as questões em aberto para revisão do grupo.

| RFC | Assunto | Status | Frente |
|---|---|---|---|
| [001](./RFC%20001%20-%20Escolha%20da%20Nuvem.md) | Escolha do provedor de nuvem | Aprovado | Reestruturação e aplicação |
| [002](./RFC%20002%20-%20Estrategia%20de%20Autenticacao.md) | Estratégia de autenticação (Lambda + API Gateway) | Aprovado | Autenticação serverless |
| [003](./RFC%20003%20-%20Escolha%20do%20Banco%20de%20Dados.md) | Escolha do banco de dados | Aprovado | Autenticação serverless |

A escolha da ferramenta de observabilidade está registrada no
[ADR 003](../adrs/ADR%20003%20-%20Observabilidade%20com%20New%20Relic.md), com a comparação entre
New Relic e Datadog.
